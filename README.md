# Spoken English for Malayalam Speakers

**മലയാളികൾക്കായുള്ള ബ്രിട്ടീഷ് ഇംഗ്ലീഷ് സ്പീക്കിംഗ് കോഴ്സ്** — ഒരു ഫയൽ, ഓഫ്‌ലൈൻ, സൗജന്യം.

ശബ്ദങ്ങൾ, വ്യാകരണം, സംഭാഷണങ്ങൾ, പദസമ്പത്ത്, അഭ്യാസങ്ങൾ, 30 ദിവസത്തെ പ്ലാൻ — എല്ലാം
ഒരു HTML ഫയലിൽ. ഇന്റർനെറ്റ് ഇല്ലാതെയും തുറക്കാം.

## ഉപയോഗിക്കുന്നത് എങ്ങനെ

1. **Live site:** GitHub Pages link (താഴെ കാണുക) അല്ലെങ്കിൽ `index.html` ഡൗൺലോഡ് ചെയ്യുക.
2. ഫോണിൽ: ഡൗൺലോഡ് ചെയ്ത ഫയൽ **Chrome / Safari**-യിൽ തുറക്കുക
   (WhatsApp-ൽ നിന്ന് നേരെ തുറക്കില്ല — ആദ്യം സേവ് ചെയ്യുക).
3. ഏത് ഇംഗ്ലീഷ് വാക്കിനും വാക്യത്തിനും അടുത്തുള്ള **🔊** അമർത്തി ബ്രിട്ടീഷ് ഉച്ചാരണം കേൾക്കാം.
4. മുകളിലെ **🔊** ഐക്കൺ തുറന്നാൽ:
   - ബട്ടണുകൾ ഓൺ / ഓഫ്
   - **വനിതാ / പുരുഷൻ** ശബ്ദം (default: വനിതാ)
   - സാധാരണ / പതുക്കെ വേഗം

## എന്തെല്ലാം ഉണ്ട്

- 17 അധ്യായങ്ങൾ — sounds, dialogues, vocabulary, grammar, drills, video library, 30-day plan
- **3,900+ pronunciation buttons** (വാക്ക്, വാക്യം, സംഭാഷണം, letter names)
- Female & male British voice (device-ന്റെ built-in en-GB voice)
- Dark / sepia theme, font size, progress ticks
- Fully self-contained: no server, no API key, no internet needed
